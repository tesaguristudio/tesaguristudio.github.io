# tesaguristudio.github.io
## 更新のお知らせ（version.json）

各アプリのフォルダの `version.json` を、アプリが起動するたびに読みます。

```json
{
  "android": { "latest": "1.2.1", "minimum": "1.0.0" },
  "ios": { "latest": "1.2.1", "minimum": "1.0.0" }
}
```

- `latest`：ストアに出ている最新の版。これより古いアプリに「新しいバージョンがあります」が出る（「あとで」で3日休む）。**ストアで公開されてから**書きかえる（審査中に上げると、まだ更新できない人に出てしまう）。
- `minimum`：これより古いアプリは「更新する」しか押せなくなる。サーバーの変更で古い版が動かなくなるときだけ上げる。ふだんは `1.0.0` のまま。
- push して数分〜10分ほどで、アプリに届く。
